# 扫地机器人智能客服与使用报告助手

基于 Python、Streamlit、LangChain/LangGraph、Chroma 和 DashScope 的 RAG + ReAct 示例项目。面向扫地机器人产品知识问答，并支持从用户月度记录生成个性化使用报告。

## 功能

- **RAG 知识问答**：加载 TXT/PDF，递归切片、Embedding 向量化并写入持久化 Chroma；按问题检索相关片段后由大模型结合上下文回答。
- **增量知识库管理**：在侧栏查看向量片段数并触发知识目录扫描；基于 MD5 跳过已处理文件。
- **来源可追溯**：回答旁可查看命中的资料片段、来源文件、页码和距离分数。
- **ReAct 工具调用**：提供知识检索、天气/位置、用户信息及个人使用记录工具；通过中间件记录调用并切换报告提示词。
- **报告数据查询**：按用户和月份读取 CSV 记录，生成使用情况报告；CSV 使用标准解析器。
- **会话与反馈**：保留当前会话、导出 JSON、清空会话，并记录用户赞踩反馈。
- **运行日志**：记录模型前状态、工具输入和执行成功/失败情况。

## 项目结构

```text
app.py                    Streamlit 应用
agent/react_agent.py      Agent 组装和流式调用
agent/tools/              工具定义与中间件
rag/vector_store.py       文件加载、切片、向量入库及检索
rag/rag_service.py        检索增强生成链
model/factory.py          聊天模型和 Embedding 工厂
config/                   模型、向量库和路径配置
prompts/                  客服、RAG 总结和报告提示词
data/                     知识库文件及外部 CSV 示例数据
```

## 启动

安装项目依赖（建议使用虚拟环境），并配置 DashScope 所需的 `DASHSCOPE_API_KEY` 环境变量。然后在项目根目录运行：

```bash
streamlit run app.py
```

首次使用时从侧栏点击“扫描并增量导入 data/”。知识库文件支持 TXT/PDF。模型名、切片策略、检索数量和数据路径可在 `config/` 中调整。

## 技术流程

```text
用户问题 → Streamlit → LangChain Agent
                       ├─ 专业问题 → Chroma 检索 → 提示词组装 → 大模型回答 + 引用
                       └─ 报告问题 → 用户/月度工具 → CSV 查询 → 报告提示词 → 大模型报告
```

## 项目边界

天气、用户位置、用户 ID 和月份工具当前是本地演示数据源；接入真实业务时应替换为天气 API、认证用户上下文和业务数据服务。当前反馈保存在会话内存中，生产使用需持久化到数据库。检索来源区域展示的是当前问题的相关命中结果，Agent 也可能根据其工具规划调用其他查询。

面试时建议明确说明：天气和用户身份目前是模拟工具，反馈暂存于会话内存；不要把这些描述成已接入的生产服务。
